# Idiomas (i18n)

<p class="lead">A interface do editor vem em português do Brasil (padrão), inglês e espanhol. Use o
seletor de idioma no topo deste site para ver os editores mudarem.</p>

## Escolher o idioma

```ts
createEditorUI(host, { i18n: { locale: 'en' } });
```

- `locale` aceita variações como `pt_br`, `pt`, `en-US` e `es-AR`.
- Idioma desconhecido cai no `pt-BR`.
- Web component: atributo `locale="en"`. Angular: segue o idioma do ngx-translate.

## Trocar depois de criado

```ts
ui.i18n.setLocale('es');
ui.i18n.onChange((locale) => console.log('idioma:', locale));
```

A barra, os menus, os diálogos e a barra de status são atualizados sem recriar o editor.

## Mudar ou acrescentar textos

```ts
import { createI18n } from '@kelsoncm/tiptap-core';

const i18n = createI18n({
  locale: navigator.language,
  messages: {
    'pt-BR': { 'editor.toolbar.bold': 'Forte' },
    fr: { 'editor.toolbar.bold': 'Gras' }, // idioma novo: o que faltar cai no pt-BR
  },
});

createEditorUI(host, { i18n });
i18n.t('editor.toolbar.heading', { level: 2 }); // "Título 2"
```

As chaves seguem o padrão `editor.<área>.<item>`. A lista completa está em
[src/i18n](https://github.com/tiptap-by-kelsoncm/tiptap-core/tree/main/src/i18n).

## Traduções de plugins

Plugins trazem as próprias mensagens em `messages`, por idioma
(veja o [exemplo de widgets]({{root}}exemplos/widgets.html)).
